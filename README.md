## Design Approach

### How I Approach Designing Software
I begin by identifying the overall goal and breaking the system into manageable components. For this project, I planned the scene layout first, determining object placement, scale, and relationships before implementing functionality. I focused on maintaining a structured and reusable design so individual elements could be refined without affecting the entire system.

### Design Skills Developed
This project strengthened my spatial design skills within a 3D environment. I learned how object scale, positioning, lighting, and textures work together to create a balanced and visually effective scene. I also improved my ability to design visual systems incrementally rather than building everything at once.

### Design Process Used
I followed an iterative design process:
1. Create a basic scene using primitive shapes  
2. Apply transformations and positioning  
3. Add textures and materials  
4. Implement lighting  
5. Refine visual balance and overall presentation  

This approach allowed continuous testing and reduced debugging complexity.

### Applying This Process in the Future
Breaking complex projects into smaller milestones and validating each step is a strategy I will continue using in future software and full-stack development work.

## Development Approach

### How I Approach Development
I focus on building a working foundation early and then expanding functionality step by step. Once the core system runs successfully, I improve structure, readability, and performance.

### New Development Strategies Used
- Incremental testing of graphical changes  
- Debugging transformation and rendering behavior through visual feedback  
- Organizing rendering and scene logic into manageable components  

### Role of Iteration
Iteration played a major role in this project. Many visual elements required adjustment through testing, including object placement, lighting intensity, and texture scaling. Making small, controlled changes helped maintain stability while improving the final result.

### Growth Through the Milestones
Throughout the milestones, my development approach became more disciplined. I focused on isolating issues, testing frequently, and refining the system gradually rather than making large changes at once.
